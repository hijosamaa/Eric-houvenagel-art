# Références — tableaux de l'artiste

Ce dossier reçoit les **photos des tableaux de référence** d'Eric Houvenagel (huile et aquarelle).

## Comment uploader

Interface GitHub (web ou navigateur mobile) : **Add file → Upload files**, destination `references/`, puis commit. (GitHub ne permet pas de créer un dossier vide : c'est ce README qui crée le dossier.)

## Conventions

- JPG ou PNG, résolution maximale de l'appareil photo.
- Lumière naturelle, sans flash, tableau de face.
- Nommage : `huile-<sujet>-<annee>.jpg`, `aquarelle-<sujet>-<annee>.jpg`.

## Utilisation

Ces images servent à :

1. Définir la palette de couleurs, la typographie et l'ambiance de la galerie 3D.
2. Pré-remplir la galerie de démonstration avec de vraies œuvres.
