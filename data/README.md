# Données des œuvres

Ce dossier contiendra les données des tableaux affichés sur le site.

Elles seront **gérées par le mode administrateur** (CMS headless) : un fichier JSON par œuvre dans `data/works/`, plus éventuellement un fichier d'ordre d'affichage. Ne pas modifier ces fichiers à la main.

Le schéma exact (champs : image, titre, année, technique, dimensions, description, salle, position, ordre) sera défini dans `docs/plan.md`.
